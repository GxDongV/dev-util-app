# 图标资源说明

## 图标文件要求

为了设置应用程序的图标，您需要准备以下图标文件：

1. **app_icon.ico** - 用于Windows应用程序的图标文件（推荐尺寸：16x16, 32x32, 48x48, 64x64, 128x128, 256x256）
2. **app_icon.png** - 用于在应用程序界面中显示的PNG格式图标（推荐尺寸：64x64 或 128x128）

## 使用方法

1. 创建符合上述要求的图标文件
2. 将图标文件放入此目录（resources）
3. 运行应用程序时会自动加载图标

## 图标设计建议

- 使用简洁、易识别的图案
- 确保在小尺寸下仍然清晰可辨
- 选择与开发工具主题相符的颜色方案
- 考虑在深色和浅色背景下都能良好显示的颜色
