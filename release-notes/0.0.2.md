# DevUtilsApp v0.0.2

面向 Windows 10/11 x64 的开发者工具集，包含命名转换、JSON/XML 格式化与互转、Base64 与摘要计算、文本统计、数字及存储单位转换，支持深浅色主题。

## 下载选择

| 发行文件 | 使用方式 |
| --- | --- |
| `DevUtilsApp-0.0.2-windows-x64-single.exe` | 单文件版：下载后直接双击运行 |
| `DevUtilsApp-0.0.2-windows-x64-portable.zip` | 绿色版：完整解压后运行 `DevUtilsApp/DevUtilsApp.exe`，保留同目录依赖文件 |
| `DevUtilsApp-0.0.2-windows-x64-setup.exe` | 安装版：运行向导安装，提供开始菜单入口、可选桌面快捷方式和卸载程序 |
| `SHA256SUMS.txt` | 三种发行文件的 SHA-256 校验值 |

以上发行文件均已包含运行环境，无需另外安装 Python。安装版默认安装到当前用户目录，无需管理员权限。应用运行日志位于用户的 `Documents/DevUtilsApp/app.log`。

## 本次发布

- 打包当前主分支中的工具功能和编码、XML 处理改进。
- 提供单文件、绿色压缩包和安装包三种 Windows x64 发行方式。
- 统一应用与安装包的版本信息，修正安装脚本中的固定路径和占位信息。
- 新增一次生成全部发行文件和 SHA-256 校验值的打包脚本。

## 本地构建

安装项目依赖和 Inno Setup 6.3+，运行 `python scripts/build_release.py`，产物位于 `release/`。
